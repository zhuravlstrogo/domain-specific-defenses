# Inspect AI Tutorials

Эта папка содержит локальные копии исходных туториалов из `~/ai_safety`.

Они нужны как reference:

- `week_1.py`: базовая структура `Task(dataset, solver, scorer)`.
- `week_2.py`: разбор `EvalLog` и статистика.
- `week_3.py`: `model_graded_qa` и LLM-as-judge.
- `week_4.py`: организация экспериментов и сравнение конфигураций.

Рабочий код проекта находится не здесь, а в `src/domain_defenses/` и `experiments/`.
